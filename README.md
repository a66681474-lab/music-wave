# Волна

Русскоязычный статический музыкальный сайт для GitHub Pages. Поиск исполнителей и песен в iTunes, обложки, встроенный плеер доступных аудиопревью, перемотка, громкость и избранное в браузере. Без регистрации и собственного сервера.

## Бесплатная публикация

1. Откройте настройки Pages: https://github.com/a66681474-lab/music-wave/settings/pages
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. В **Branch** выберите **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь окончания публикации. Точный адрес появится на этой странице рядом с кнопкой **Visit site**. Если процесс завершился ошибкой, откройте вкладку Actions и проверьте Pages build and deployment.

При последующих изменениях в main GitHub Pages обновит сайт автоматически. Публикация Pages в рамках этой подготовки не подтверждена: доступные инструменты позволяют записать файлы репозитория, но не изменить настройку Pages.

## Проверка после публикации

- Откройте сайт по адресу, который покажет GitHub.
- Введите Billie Eilish и нажмите «Найти». Должны появиться реальные результаты и обложки.
- Запустите доступное превью. Убедитесь, что счётчик времени меняется и звук слышен; проверьте паузу, перемотку и следующую песню.
- Добавьте песню в избранное, перезагрузите страницу и откройте «Избранное».
- Проверьте другой регион каталога, поиск на русском, пустой результат и узкий экран телефона.
- Проверьте ссылку Apple Music на карточке песни.

Браузерная проверка и фактическое воспроизведение ещё не выполнены: у этой задачи нет доступного устройства с браузером. Запись файлов в GitHub не является подтверждением успешной публикации или проверки.

## Ограничения

- Только официально доступные короткие превью, не полные треки. Полная песня открывается в Apple Music и может требовать подписку.
- Доступность каталога, обложек и аудио зависит от страны, подключения и ограничений Apple. Часть песен не имеет превью. Каталог может ограничивать частые запросы; предусмотрены сообщения об ошибках и повтор.
- Кнопки исполнителей — редакционная подборка, не актуальный чарт. Поиск не гарантирует наличие каждого современного исполнителя.
- Избранное хранится локально в localStorage, не синхронизируется между устройствами и исчезает при очистке данных браузера. Максимум 300 записей. Если сохранение запрещено браузером, используется временная память страницы.
- Данные поиска передаются Apple через публичный iTunes Search API с JSONP. Обложки и аудио загружаются с серверов Apple; шрифт — с Google Fonts, с системным запасным шрифтом.
- Нет аккаунтов, загрузки музыки, собственного музыкального каталога, платежей, серверной базы или секретных ключей.

## Файлы

- `index.html` — интерфейс и доступные SVG-иконки.
- `styles.css` — единое оформление, адаптивность и состояния элементов.
- `app.js` — поиск, плеер, обработка ошибок и избранное. Названия из каталога вставляются через textContent; внешние ссылки, аудио и обложки проверяются по допустимым HTTPS-доменам Apple.
- `.nojekyll` — публикация статических файлов без Jekyll.

Не связано с Apple Inc. Названия, аудиопревью и обложки принадлежат соответствующим правообладателям. Перед коммерческим использованием необходимо отдельно проверить условия iTunes Search API и права на контент.
